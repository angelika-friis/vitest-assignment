# Vitest-assignment

Inlämningsuppgift i kursen agil projektmetodik och testning.

## Innehåll:
- Kalkylator funktion som kan utföra addition, subtraktion, multiplikation och division
- Enhetstest för kalkylatorn skrivet med vitest
- Frontendapp med inloggning mot rest-api med jwt-hantering. Med funktion att lägga till en film samt visa adderade filmer.
